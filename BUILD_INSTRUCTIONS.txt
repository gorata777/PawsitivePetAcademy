PAWSITIVE PET ACADEMY — BUILD NOTES

1. Extract the ZIP. In Android Studio use File > Open and select the PawsitivePetAcademy folder (not the ZIP).
2. Set Gradle JDK to JDK 17, install Android SDK 35 and disable Gradle Offline mode.
3. IMPORTANT: This archive contains the Gradle 8.9 distribution pin in gradle/wrapper/gradle-wrapper.properties but does NOT contain gradle-wrapper.jar or gradlew launch scripts. A Gradle 8.9 installation or a wrapper generated by a trusted Gradle installation is required.
4. To generate the wrapper, from the project root with Gradle 8.9 installed run: gradle wrapper --gradle-version 8.9
5. Reopen/sync the project. Avoid Gradle 9 with Android Gradle Plugin 8.7.3; it can cause configuration errors such as debugRuntimeClasspathCopy.
6. If sync still fails, copy the entire first error and its stack trace; do not assume this package was compiled.

This ZIP has been statically inspected, but Android SDK, Gradle and a full Android build are unavailable in this environment.
The app uses local device storage; payment processing, account authentication, remote notifications and sending email automatically are not implemented.
The Contact Us form opens the device's email application for the user to send a message.
The map opens Google Maps/browser directions to Durban, South Africa; no street address was supplied.
