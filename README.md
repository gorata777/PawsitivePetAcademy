# Pawsitive Pet Academy

Pawsitive Pet Academy is a pet-care education Android application for browsing seven courses, estimating fees, registering locally, viewing enrolled courses and tracking module progress.

It includes the twelve screens shown in the supplied wireframes: Home, About Us, Courses, Course Details, Calculate Fees, Registration, Registration Success, My Courses, Learning Progress, Profile, Contact Us and Navigation Menu.

Contact: magogodigorata63@gmail.com | 078 751 3255. Location link: Durban, South Africa (general destination until an exact address is supplied).

The application stores registration and progress data locally. Registration does not collect payments. Email enquiries are composed in an installed email application and require the user to press Send.

See BUILD_INSTRUCTIONS.txt for build environment requirements and limitations.

Branding: the launcher icon and in-app header use the matching forest-green paw-and-book academy logo.
